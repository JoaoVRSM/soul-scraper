Seu site pede.

Seu próprio site envia para a FastAPI o endereço de outro site autorizado. A Soul Scraper faz a raspagem e devolve o catálogo JSON diretamente para o seu site importar, salvar ou exibir.

FLUXO DIRETO

Uma requisição, três etapas

Só a URL do site de origem é obrigatória. A resposta volta para quem fez a requisição.

01
↗

Seu site faz o pedido

O backend do seu site envia um POST com a URL do site que será raspado.

02
◎

A FastAPI busca os dados

O crawler percorre o outro site autorizado e organiza filmes, séries e players.

03
{ }

O JSON retorna

Seu site recebe a resposta e pode gravar no banco, importar ou mostrar os dados.

INTEGRAÇÃO

Coloque no backend do seu site

Troque https://sua-api.com pelo endereço onde esta FastAPI estiver publicada.

Recomendado: faça esta chamada no backend do seu site. Se chamar direto do navegador, libere somente o domínio do seu frontend com --cors-origins.

ENDPOINTS

Direto ou assíncrono

POST/api/v1/scrape

Envie {"url": "seu-site.com"} e receba o JSON.

RECOMENDADO
POST/api/v1/crawls

Inicia em segundo plano para sites muito grandes.

GET/api/v1/crawls/{id}

Consulta o progresso da raspagem assíncrona.

GET/api/v1/crawls/{id}/catalog

Obtém o catálogo após a conclusão.
